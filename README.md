# Draw

Draw app is a web-based vector graphic editor. My hope is that its usage will be relatively self-explanatory with moderate exploration.

# Adding

The Circle tool is selected by default. The Shape menu also includes options for Line, Ellipse, and Rectangle which can be selected by expanding the drop-down. The Pen and Brush tools can also add elements.

# Modifying

The main tool for manipulating existing objects is the Select tool. Clicking an object with the Select tool enabled will highlight the object and its anchors, enabling them to be dragged. With an object selected, click on an anchor to see the anchor handles, which can be independently manipulated. 

# Shortcuts

Some keyboard and mouse shortcuts are supported. 

## Keyboard

- Delete: delete selected object

## Mouse

- Mouse button 3 (hold): Pan
- Mouse button 4: Undo
- Mouse button 5: Redo
